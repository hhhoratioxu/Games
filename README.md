# 🎮 Games

这里是我的小游戏合集仓库，用来集中整理、维护和持续更新我制作的各种游戏项目。

每个游戏都会放在独立文件夹中，互不干扰。进入对应游戏目录后，可以查看该游戏自己的介绍、玩法、操作方式和源代码。

## 规划

这个仓库会继续加入更多小游戏。每个新游戏都使用独立目录，并保留自己的说明文档和运行文件，让整个仓库保持清晰、方便维护。

## 技术

不同游戏可能会使用不同技术，包括：

- HTML / CSS / JavaScript
- Canvas
- Web Audio API
- 其他适合小游戏开发的 Web 技术
